# ShoppingList — APK для тестирования

Это **прототип** приложения «ShoppingList» (список покупок с датами, календарём и напоминаниями) — только для тестирования. Код приложения здесь не хранится, только готовые файлы установки (APK) в разделе [Releases](../../releases).

## Как установить
1. Откройте [последний релиз](../../releases/latest) на телефоне и скачайте файл `ShoppingList-….apk`.
2. Откройте скачанный файл. Если телефон спросит, **разрешите установку из этого источника** (один раз).
3. Нажмите «Установить».

## Требования
Нужен **64-битный Android** (arm64). Если телефон пишет «приложение несовместимо» — сообщите, пожалуйста.

## Как обновить
Приложение само проверит новую версию при запуске. Если вышла новая, оно предложит скачать её. Скачайте APK и **установите поверх** старой: списки и товары сохранятся. Удалять приложение не нужно.

## Файл `latest.json`
Приложение читает из него номер последней версии и заметки. Ничего о вас на сервер не отправляется.
